器件

斜镜会改变光路方向；分光器会把一束光拆成两束；带锁的镜子不可旋转。

游戏规则

  1. 光源会持续发出光束。点击可动镜子，让它在 / 与 \ 两种方向之间旋转。
  2. 光束被镜面反射后会继续前进，经过晶体即可点亮；所有晶体点亮才能过关。
  3. 紫色分光器会将一束光分为直行和右转两束。带锁图标的镜子是固定器件。
  4. 每关旋转次数越少越好。提示会短暂标出本关下一面需要调整的镜子。
